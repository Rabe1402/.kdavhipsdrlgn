# Web-Grundlagen – Abgaben-Repo für Modul IT-20

Ein Repository für **alle Aufgaben** des Moduls *IT-20 Web-Grundlagen* (HTML, CSS, JavaScript, JSON, Markdown).
Die genauen Aufgabenstellungen stehen in den Teams-Assignments.

## So startest du (nur bei der ersten Aufgabe)
1. Auf GitHub bei dieser Vorlage **„Use this template“ ➔ „Create a new repository“** klicken.
2. Name: `it20-web-<dein-kuerzel>` (z. B. `it20-web-mmuster`), Sichtbarkeit: **Public** (wichtig – die Lehrkraft muss reinschauen können).
3. Das neue Repo in **GitHub Desktop** klonen und in der **Antigravity IDE** (alternativ VS Code) öffnen.
4. Ab der zweiten Aufgabe **dasselbe Repo weiterverwenden** – kein neues Repo anlegen.

## Ordner
| Ordner | Aufgabe | Datei(en) |
|---|---|---|
| `aufgabe-1-html-css/` | 20.1 HTML & CSS | `meine-seite.html`, Screenshot |
| `aufgabe-2-javascript/` | 20.2 JavaScript | `meine-seite-interaktiv.html`, Screenshot |
| `aufgabe-3-json/` | 20.3 JSON | `meine-sammlung.html`, Screenshot |
| `aufgabe-4-markdown/` | 20.4 Markdown | `mein-text.md`, `mein-text.html`, Screenshot |

Lege deine Dateien im jeweiligen Ordner ab (die `.gitkeep`-Dateien kannst du löschen).

## Abgabe
Änderungen in GitHub Desktop links prüfen, Commit-Summary eingeben, **Commit to main** und **Push origin** klicken.
Dann in Teams den **Link zu deinem Repo** (bzw. zum Aufgabenordner) abgeben.

> ⚠️ Das Repo ist öffentlich: keine Passwörter, keine persönlichen Daten (Adresse, Telefonnummer, Fotos anderer Personen) einchecken.
